# Examples

- `core-customtype`: Qt's built-in QtCore custom-metatype example, with no
  GUI, QML, framebuffer, or font dependency.
- `widgets-controls`: interactive QWidget controls, font, style, timer, and
  input validation through the framebuffer QPA, without QML.
- `qml-smoke`: headless QML/QV4 parsing, JavaScript, allocation, and GC test.
- `qml-dashboard`: interactive software-rendered Qt Quick Controls 2 dashboard
  used as the default visual QML validation demo.
- `quick-tvtennis`: Qt's built-in TV Tennis animation running through the Qt
  Quick software scene graph and the RT-Thread framebuffer platform.
- `quick-gallery`: Qt Quick Controls 2 Gallery, the primary interactive and
  visual QML validation demo.
- `quick-automotive`: the full Qt Quick Controls 2 Imagine Automotive example,
  retained as an experimental stress test for image composition.
